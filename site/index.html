每一次捕获都有迹可循。卡片自动记录来源 App、窗口标题与项目路径； 按天分组、按项目归档；搜索、检索与回放共享同一份数据。

多种收集方式。已接入 MCP 的工具里说一句话即可逐条入库；任何 App 里选中文字按 ⌥⇧S；原生 App 右键走系统服务；网页 AI 对话装浏览器插件，自动附带原对话链接。

MCP NATIVE

对 AI 说一句话

Claude Code / Codex / ZCode / Antigravity 等已接入 MCP 的工具里，说一句「把这几条建议记到收件箱」， AI 自动拆好、逐条入库，来源工具和项目路径自动带上。

GLOBAL HOTKEY

全局快捷键

任何 App 里选中文字按 ⌥⇧S——终端、Electron 应用、浏览器通通覆盖。对话式小窗弹出确认，还能顺手记一句想法。

SERVICES MENU

系统右键服务

Safari、文本编辑、访达等原生 App 里，选中文字右键 → 服务，一样进箱，零学习成本。

BROWSER EXTENSION

浏览器插件

网页版 AI 对话里选中文字右键直达，卡片自动附带原对话链接，随时跳回上下文。

隐私 LOCAL-FIRST

你的建议，只属于你的 Mac。

SQLite 单文件存在本机，无账号、无云端、无追踪；AI 拆步调用你自己配置的模型 API，Key 只存本地。
