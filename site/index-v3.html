每次捕获都有迹可循。卡片自动记录来源 App、窗口标题与项目路径； 按项目归拢、按天分组，搜索与回放共享同一份本地数据。

多种收集方式。任何 App 里选中文字按 ⌥S；整块内容 ⌥Z 框选，跨行段落自动重组成完整文本； 已接入 MCP 的工具里说一句话即可逐条入库；网页 AI 对话装浏览器插件，自动附带原对话链接。

GLOBAL HOTKEY · ⌥S

划词即捕获

任何 App 里选中 AI 的回复按 ⌥S——终端、Electron 应用、浏览器通通覆盖。系统级直读选区，不污染剪贴板；小窗确认入库，顺手记一句想法。

BOX SELECT · ⌥Z

框选整块收

回复太长不想划？⌥Z 框一圈，命中的跨行段落自动重组成完整文本——聊天窗口里的长回复、演示里的代码块，一框进箱。

MCP NATIVE

对 AI 说一句话

Claude Code / Codex / ZCode 等已接入 MCP 的工具里，说一句「把这几条建议记到纳言」，AI 自动拆好、逐条入库，来源工具和项目路径自动带上。

BROWSER EXTENSION

网页 AI 专用通道

网页版 AI 对话里划词右键直达、快捷键框选整段，卡片自动附带原对话链接，随时跳回上下文。

隐私 LOCAL-FIRST

你的建议，只属于你的 Mac。

SQLite 单文件存在本机，无账号、无云端、无追踪；AI 拆步调用你自己配置的模型 API，Key 只存本地。
